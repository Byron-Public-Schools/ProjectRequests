# 💡 Project / Repository Request

Thanks for stopping by! Are you a student or club member at Byron Public Schools with an idea for a project, tool, website, or utility? You can request a new repository or space under our organization by filling out the details below.

> **Note:** Because this is a student-run organization, requests are reviewed by our student maintainers. Please make sure your idea aligns with school guidelines and is appropriate for a public repository.

---

## 📝 Request Form

Please copy and fill out the sections below and paste them into a new issue.

### 1. Project Title
*What is the name of your project?*
> [e.g., Byron Esports Tracker, Chemistry Study Flashcards, Robotics Bot Code]

### 2. Project Description
*Tell us briefly what your project does, who it's for, and why it would be useful.*
> [Write 1-3 sentences describing your idea...]

### 3. Tech Stack / Languages
*What programming languages, frameworks, or tools do you plan to use?*
> [e.g., Python, HTML/CSS/JavaScript, React, Arduino, etc., or "Not sure yet"]

### 4. Who's Involved?
*Are you working on this solo, or do you have a team? List the GitHub usernames of anyone who needs access.*
> [List usernames or state "Just me for now"]

### 5. Repository Name Preference
*What would you like the GitHub repository URL to be named? (Must use hyphens instead of spaces)*
> [e.g., `byron-esports-tracker`]

---

## 🚦 What Happens Next?

1. **Review:** Our team will review your request within a few days. We might ask a few questions to understand the scope.
2. **Setup:** If approved, we will create the repository for you and add you (and your team) with the appropriate permissions.
3. **Build:** Start coding, learning, and building awesome things! 🐻🖤💛
